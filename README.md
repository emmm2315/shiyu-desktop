# 时屿 · 桌面组件

一个用于 Windows 的原生小组件。展开为 340 × 460，收起为 286 × 86（逻辑像素，随系统缩放）。采用 C# / Windows Forms 和系统自带的 .NET Framework，不使用浏览器内核，不需要 Node、Python 或联网运行。

这是 **v1.2.1 弹窗修复版**。双击 **时屿.exe** 即可使用。`时屿.exe.config` 请与程序放在一起。面向 Windows 10 / 11（.NET Framework 4.7.2 或更新版本）。

已有计划、日程和计时数据沿用同一个本机数据目录。目录中已清理旧版本启动程序，保留当前版本与便携包。

v1.2.1 修复「三件事」及番茄钟设置弹窗被置顶主窗遮挡、设置时似乎卡住的问题。输入、阅读和确认窗口统一管理层级；编辑期间主窗暂时收起内容，托盘和快捷键会唤回当前弹窗。弹窗外围采用真实通透玻璃，正文和输入区保持清楚的底色；关闭后恢复主窗内容与原有置顶状态。

## 功能

- 自定义小时、分钟、秒；5 / 15 / 30 分钟快捷预设；开始、暂停、继续、重置。
- 番茄钟默认 25 分钟专注、5 分钟短休息、每 4 个番茄后 15 分钟长休息。可修改所有时长、轮数，以及是否自动进入下一段。
- 番茄钟可以关联计划，记录每日完成番茄数与专注分钟数。跳过阶段不会增加专注统计。
- 日程与计划支持添加、编辑、删除、完成、日期与可选时刻，以及每天 / 每周重复。
- 月历可切换月份，标出有安排的日期，点击日期查看当天内容。
- 每日日程可切换日期，按时间展示日程，并保留无指定时间的待办；从所选日期直接添加事项。完成状态按对应日期保存。
- 到点时显示短暂、不抢焦点的提醒小窗，支持关闭提示音；托盘可查看最近提醒。
- 跟随系统浅色 / 深色主题；也可在设置中固定主题。
- 默认通透玻璃：Windows 11 24H2 及更新版本使用原生透明合成，保留极淡的底色、细高光边缘和清晰的文字；卡片和按钮也半透明。
- 设置可在「通透玻璃」「柔和毛玻璃」「实色背景」之间切换，并调整底色浓度。柔和毛玻璃采用 Windows 11 22H2 起支持的 Desktop Acrylic；系统透明设置、节电模式与窗口状态可能影响其效果。更早的系统会回退为可用背景。
- 位置记忆、边缘吸附、置顶、迷你条和托盘。
- 本机自动保存。退出或重开后，正在进行的计时会继续按原定结束时刻计算。
- 专注小植物：完成番茄钟后从种子到发芽、长叶、开花，点击查看七天记录；没有持续动画。
- 下一步抽签：从今天和逾期的未完成计划里抽一项，支持仅抽预计不超过 15 分钟的小事。
- 今日三件事：每天最多三个重点，顶部显示完成数量，完成全部后短暂亮起细边。
- 明天接着做：每项任务保存一句下一步，开始专注前显示；专注结束点击提醒可继续记。自动番茄模式会在新专注的提醒里显示。
- 重要日倒数：支持一次性日期和每年纪念日，底部每分钟轮流显示。
- 随手记气泡：快捷记录想法，可转成计划或日程，完整正文保存在任务说明中。
- 一日小结：每天完成数量、专注时长和心情文字；有学习活动时，晚 21 点后每天最多温和提示一次。
- 三个可单独导入的学习包：8086 寄存器入门（7天、14项）、操作系统原理（14天、28项）、算法分析与设计（14天、28项）。每项有预计用时、练习和验收条件。

沿用原生轻量架构，没有新增常驻动画循环。前一版在本机 Windows 11、150% 系统缩放下的短时空闲参考测量：工作集约 51 MB，私有内存约 28 MB；CPU 约占一个逻辑核心的 0.16%。记录见 `artifacts/previews/runtime-check.txt`。

## 操作

拖动顶部移动位置。顶部图钉切换置顶，横线收成迷你条，× 隐藏到托盘。双击托盘图标可唤回；右键托盘选择「退出」才会彻底结束程序。

点击计时器中央数字自定义时长；点击番茄钟顶部的任务条关联计划。日程页可切换「月历」「每日」「清单」。月历和每日视图点击 ＋ 向选中的日期添加；清单视图默认向今天添加。点击标题编辑，点击圆圈标记完成，点击 ··· 可以编辑、开始专注或删除。条目多时用鼠标滚轮查看。

底部的小星形打开「小趣味」菜单；右键设置和托盘也有入口。顶部「三件事 / 重点」直接挑选每日重点。任务的 ··· 菜单可打开「任务说明与练习」「记下下一步」。学习包入口在小趣味菜单底部，先查看完整练习，再选一个开始日期加入；同一学习包只导入一次，避免重复计划。不同课程可以使用不同开始日期。

学习包导入后，计划每天两项，概念约 10 分钟、练习约 20 分钟，均不指定固定时刻。导入只在该日没有重点时选入本包的两项，不替换已有重点。预计用时是练习建议，可按课程进度修改日期、时长和正文。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + Alt + Space | 全局显示 / 隐藏组件 |
| Ctrl + Alt + N | 全局快速添加日程或计划 |
| Ctrl + 1 / 2 / 3 | 窗口内切换功能 |
| Space | 窗口内开始 / 暂停当前计时 |
| Ctrl + R | 窗口内重置当前计时 |
| Ctrl + N | 窗口内新增计划 |
| Ctrl + J | 窗口内快速随手记 |
| Tab / Shift + Tab / Enter | 窗口内选择与执行按钮 |
| Esc | 隐藏到托盘 |

如果全局快捷键已被其他软件占用，可通过托盘操作。设置中的「快捷键与说明」会显示注册结果。

## 用 AI 设计或调整学习计划

项目提供 [学习计划 Prompt 合集](docs/prompts/README.md)，包含 8 个场景模板，以及 [通用 Prompt](学习计划设计与导入-Prompt.md)。可以用它们设计新课程、接入已有计划、修改学习包模板、调整已导入任务，或提出计划功能的开发需求。

复制对应文档中的完整 Prompt，填写课程、资料、学习时间和修改范围即可。普通聊天 AI 适合生成计划草案；接入学习包、修改程序或更新本机任务，需要能访问本项目及相关数据的 AI 编程助手。

当前版本通过内置学习包导入计划。Prompt 合集中的 JSON 文件导入属于待开发功能；修改学习包模板也不会自动更新已经导入的任务。

## 日程和计时规则

重复计划的日期为起始日期；每天从这天起重复，每周在同一星期几重复。勾选只完成对应的一次，下一次仍会出现。「今天」包含当天计划及未完成的过期一次性计划，「全部」展示未完成条目，「完成」展示已完成条目。

「每日」只显示所选日期本身的安排，按指定时间排序，无时刻待办排在后面并保留加入顺序，因此课程当天的概念任务排在练习前。月历的圆点表示当天有安排。重复项保留同一条计划，以日期键分别记录完成情况；一次性任务有独立完成状态。清单中今天补做的过期任务计入今天的小结；在月历或每日视图明确标记某日完成，则记在所选日期。取消完成会撤销原完成日期的计数。

每日重点与小结按本机日期保存。把重点任务改到未来、改成日程或修改重复规则后，失去该日资格的重点引用会自动清理；删除任务同时清理其重点和下一步引用。下一步按任务保存，自由专注另有一条。小植物从每日已完成的番茄统计绘制，跳过和重置不增加生长。

电脑睡眠或程序退出期间无法发出提醒。恢复运行后，已经结束的计时和未提示的一次性日程会补发提醒；重复日程检查当天。提醒小窗约 9 秒后关闭，点击可查看完整内容，托盘也可查看最近一批提醒。空闲时以 10 秒间隔检查日程。番茄钟在休眠期间只计入实际到点的一段，避免将无人操作的多个小时计为多轮专注。

默认每段结束后手动开启下一段。修改番茄设置会重置当前番茄进度。选择新计时预设或自定义时长也会重置该倒计时。

## 数据和隐私

数据位于 `%LOCALAPPDATA%\DeskSprout\state.json`，备份为 `state.json.bak`，错误记录为 `error.log`。不上传数据，不安装服务，不修改开机启动。复制 JSON 文件即可备份；关闭程序后恢复备份。数据异常时会保留原文件并尝试恢复备份。

## 开发与验证

在项目目录用 PowerShell 运行：

```powershell
.\build.ps1 -Test -Preview
```

旧程序正在运行时，可输出到新文件，避免覆盖正在使用的程序：

```powershell
.\build.ps1 -Test -OutputPath .\artifacts\时屿-待替换.exe
```

脚本调用 Windows 的系统 C# 编译器，不需要额外安装 SDK 或 NuGet 包。核心、日程、小功能和课程包测试覆盖计时状态、番茄周期、跨月和闰日重复安排、所选日期完成与撤销、抽签候选、笔记转换、每日重点、小结、学习包独立去重、旧版数据兼容、持久化与数据恢复。`-Preview` 生成的浅色、深色及迷你条预览保存在 `artifacts\previews`，本次 v1.2.1 的检查结果保存在 `artifacts\previews-v1.2.1`。

v1.2.1 的验证包含 41 项逻辑测试、6 项界面流程检查与 10 项真实 Windows 弹窗回归：置顶/非置顶窗口顺序、输入窗口关闭后恢复、番茄钟实际保存与取消、托盘操作阻断、玻璃外框的裁剪与释放。浅色、深色透明层另有渲染检查。课程完整题目位于 `课程练习` 文件夹，详细规则见 `每日任务实现说明.txt`。

`src/Core.cs` 为计时与计划逻辑，`src/ExtrasCore.cs` 为小功能持久化，`src/LearningPack.cs` 与 `src/UniversityPacks.cs` 为课程练习及导入逻辑，`src/MainForm.cs` / `src/ExtrasView.cs` 为桌面交互，`src/CalendarView.cs` 为月历和每日视图，`src/Dialogs.cs` / `src/ExtrasDialogs.cs` 为输入弹窗，`src/WindowDialogs.cs` 管理弹窗层级与模态状态，`src/ModalGlassFrame.cs` 为通透弹窗外框，`src/Backdrop.cs` 为原生玻璃合成。修改功能后重新编译即可。玻璃静态预览使用程序生成的示意背景，不截取桌面或其他应用；实际桌面透明和模糊由 Windows 合成。

透明合成使用 Microsoft 文档中的 [DWMWA_REDIRECTIONBITMAP_ALPHA](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)，将逐像素透明度交给 Windows；外观采用淡底色与细高光，并未实现苹果材质的光学折射。
