# 07 · 新增 JSON 导入功能

适用于能访问时屿仓库的 AI 编程助手，开发并验证外部学习包文件导入与更新。当前版本只支持源码中的内置包，本模板提出的是待开发能力。

## 可复制 Prompt

```text
你是时屿的开发助手。请按以下需求实现从 JSON 文件导入学习包的功能，交付可使用的新构建和对应文件规范，不要仅给方案。

【参数】
主要需求：[填写，例如普通 AI 生成文件后由用户选择导入]
日期方式：[导入时选开始日期；允许的星期与暂停日要求]
重复与更新要求：[默认重复导入跳过；同一包新版预览后更新未完成任务]
需要支持的任务字段：[默认标题、预计分钟、说明、下一步；其他明确填写]
示例课程与每日预算：[填写]
界面要求：[例如现有学习任务包菜单增加“从文件导入”]
输出位置：[默认 docs/learning-pack-json.md 及 examples/learning-packs/]
实际数据操作：[默认不导入我的实际计划，仅交付功能；若要求现在导入，写明文件和开始日期]

【读取与范围】
先读项目指令、README.md、每日任务实现说明.txt、src/LearningPack.cs、src/UniversityPacks.cs、src/ExtrasView.cs、src/ExtrasCore.cs、src/Core.cs、build.ps1 和相关 tests。保留原生 C# / WinForms、离线使用及内置包入口。
当前按包 Id 去重，运行时任务 Id 在导入时生成，旧实例没有可靠来源包或任务标识；JSON 入口及批量更新 API 需开发。以实际源码为准。

【格式与日期】
1. 实现后交付真正支持的规范与完整示例。定义格式版本、稳定包标识、内容修订版本、稳定来源任务标识；与运行时 Id 区分，改标题或排序不改来源标识。
2. 明确字段、类型、范围、日期/时刻格式、重复与未知字段处理、支持版本、文件大小及任务数上限。拒绝非法输入，不悄悄忽略影响计划的字段。
3. 区分学习日编号与日历偏移；当前 Day 为从 0 起的日历天偏移。星期与暂停日按实际开始日期映射并预览，换日期后重新计算。
4. 按当前校验，标题不超过界面 120 字符、说明 4000、下一步 500、预计分钟 1–480。每日预算包括复习与自测；检查超预算、无可学习日、日期溢出及所支持的时刻冲突。

【导入与更新】
1. 提供选文件、预览、提交及结果反馈。预览列出包/修订、日期、任务数、每日时长和新增、更新、跳过、冲突明细；完整校验后才允许写入。
2. 校验失败不写任何任务、映射或标记。保存失败不留部分写入或成功提示，恢复内存状态以防后续误保存；沿用受控持久化，不覆盖运行中的 state.json。
3. 默认重复导入不增加任务，换日期不建第二批。明确同一修订、新修订、回退、缺失任务及冲突规则，不改包 Id 或清标记绕过去重。无第二期需求就不扩展此能力。
4. 新实例持久化来源映射与必要基线，以识别用户修改。默认只更新未完成且无手动修改冲突的字段，完成项、冲突项和缺失项不删除。旧实例不得按相似标题关联；保持原状或由用户显式核对映射。
5. 保留运行时 Id、完成状态/日期、重复完成记录、专注统计、提醒、用户说明、下一步及重点引用。UpdateItem 显式保留原重复规则与提醒值；明确改变时保护完成历史。已有重点不替换，无重点时最多自动选两项。
6. 新字段兼容旧数据缺省值，原课程、手动任务及历史正常加载。仅在参数明确要求时操作实际数据，事前备份。

【验证与交付】
使用独立临时数据验证：有效导入、非法文件与字段、超限与日期溢出、星期映射、重复导入、修订更新、用户修改冲突、已完成任务保留、旧数据兼容、保存失败及重新加载。提交成功须检查 LastSaveError 并重新读取验证，不能只看新增数量。
在仓库根目录运行适用构建和测试；若原程序运行，使用 ./build.ps1 -Test -OutputPath ./artifacts/时屿-待替换.exe，保留对应 .config，检查实际界面入口和预览。
交付改动文件、实际测试结果、已验证的 JSON 规范与示例、供普通 AI 按此规范生成文件的 Prompt，以及程序和菜单操作步骤。明确本次是“功能已实现并验证”还是“已导入实际计划”，列明未完成或无法验证的部分。
```

## 填写示例

把下面内容填入上面的完整 Prompt；示例不能单独代替完整开发要求。

```text
主要需求：从 JSON 文件导入自定义课程，并支持同一包新版更新
日期方式：导入时选择开始日期，支持周一至周五及指定暂停日期
重复与更新要求：重复跳过；新版只更新未完成且未被手动修改的任务，冲突保留
需要支持的任务字段：标题、预计分钟、说明、下一步；不需要固定时刻或重复任务
示例课程与每日预算：Python 字典入门，5 个学习日，每天 30 分钟，题目自编
界面要求：学习任务包菜单增加“从文件导入”，提交前查看日期与变化清单
输出位置：docs/learning-pack-json.md 及 examples/learning-packs/
实际数据操作：不导入实际计划，使用临时数据测试并交付新构建
```
