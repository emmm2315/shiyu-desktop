# 02 · 新建可导入学习包

适用于给时屿增加一门新课程。请在能访问本仓库的 AI 编程助手中使用；默认交付可导入构建，由用户在组件中加入计划。

## 可复制 Prompt

```text
你是时屿的学习计划设计与开发助手。按下面需求设计课程并接入内置学习包，完成构建与验证，本次不写入真实计划数据。

【填写参数】
课程与范围：[填写]
当前水平与已完成内容：[填写]
教材或资料：[仓库相对路径、章节或粘贴资料]
周期：[例如 14 个学习日]
每日预算：[例如 30 分钟]
开始日期：[YYYY-MM-DD；连续日程可导入时选择]
可学习日期与休息日：[填写]
任务偏好与验收目标：[填写]

【执行规则】
1. 路径与命令相对于仓库根。先读项目指令、README.md、每日任务实现说明.txt、src/LearningPack.cs、src/UniversityPacks.cs、src/ExtrasView.cs、src/ExtrasDialogs.cs、src/ExtrasCore.cs、src/Core.cs、build.ps1 和相关测试。当前只支持源码内置包，以实际代码为准。
2. 按前置知识安排概念、练习、复习与自测；每项含目标、具体动作、自检、完成标准与下一步。每日合计不超预算，不编造教材页码和题号。非关键项留空时采用并说明默认值：连续 14 天、每天 30 分钟、无固定时刻、一次性任务、提醒关闭。缺少关键目标或无法确定日期规则时集中询问，答复前只做不依赖这些信息的工作。
3. LearningTask.Day 是从 0 开始的日历偏移，日期为 startDate.Date.AddDays(Day)。按星期排课须用最终开始日期计算，或限制到核定日期；不能只写“周末休息”。包 Days 为最大偏移 + 1，含休息日，区分学习日数量与日历跨度。
4. 标题最多 120 字符、Detail 最多 4000、NextStep 最多 500；Minutes 为整数 1–480。导入直接构造任务，新增包须在写入前完整校验，超长正文放“课程练习”文件。
5. 使用稳定无冲突的包 Id，注册到 LearningPack.All；保留按 Id 一次去重和已有重点，空重点日最多选本包两项。每日项数变化时修正固定文案。同步完整练习、预览、导出及适用来源，不沿用其他学科参考文献。保持原生轻量离线；新增源码文件时核对测试编译列表。

【验证与交付】
在仓库根运行适用构建测试，例如 .\build.ps1 -Test -OutputPath .\artifacts\时屿-待替换.exe，保留对应 .config，不覆盖运行中的程序或数据。用独立临时状态核对任务数、日期、休息日、预算、重复导入及旧任务保留；检查 LastSaveError，再重新读取确认保存。
交付逐日计划、练习文件、改动与实际测试结果、构建路径和“小趣味 → 学习任务包 → 本课程 → 选择开始日期，加入计划”的步骤。明确已接入可导入包，本次未写入真实计划；验证受限时如实说明。
```

## 填写示例

以下只是填写示例，请替换上方完整 Prompt 的参数后执行，不表示已经接入或导入。

```text
课程与范围：离散数学的集合、关系与函数
当前水平与已完成内容：会基本集合运算，尚未学习关系与函数
教材或资料：使用我附上的课件，不编造页码和题号
周期：10 个学习日
每日预算：30 分钟
开始日期：2026-10-05
可学习日期与休息日：周一至周五，周末休息；改选开始日期时重算偏移
任务偏好与验收目标：概念 10 分钟 + 练习 20 分钟，能判断关系性质并完成基础证明
```
