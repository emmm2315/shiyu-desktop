# 05 · 调整已导入计划

适用于延期、减量或修改已经加入日常计划的未完成任务，并保留历史与个人记录。需要能访问目标数据的助手；不能只凭课程名称或相似标题批量覆盖。

## 可复制 Prompt

```text
你是时屿的日程维护助手。核对以下已导入任务，只调整指定范围内的未完成项，保留完成历史与个人记录，并验证保存结果。

【填写参数】
课程或计划：[填写]
目标任务：[优先提供真实 Id；否则逐项给出原标题、原日期及可核对信息]
目标日期范围：[YYYY-MM-DD 至 YYYY-MM-DD]
调整方式与允许修改字段：[延期 / 排期 / 改内容，注明字段]
暂停日期、可学习日期与每日预算：[写具体日期，考虑同日其他安排]
必须保留的内容：[填写]
目标数据：[位置或“按当前实例查找并核对”]
应用方式：[预览差异 / 核对无歧义后执行；默认后者]

【执行规则】
1. 项目路径相对于仓库根。先读项目指令、README.md、src/Core.cs、src/ExtrasCore.cs、src/LearningPack.cs、src/Program.cs 和相关测试，核对目标数据与保存接口。当前任务没有可靠包来源字段，导入标记不是条目映射；不能只凭相似标题、前缀或推算日期批量覆盖。歧义对象先请求必要信息，期间只交付其预览。
2. 列出逐项 Id、原值与拟改值，保持顺序，预算不足则顺延，不压低估时来隐藏超时。日期用 YYYY-MM-DD，真正跳过暂停日与周末，核对跨月和结束日。
3. 仅改获准字段，保留 Id、完成状态与日期、CompletedOccurrences、专注统计、正文、下一步、重复规则、提醒及其他记录。调用 UpdateItem 时显式传入原 Repeat、ReminderEnabled 等原值；其默认参数会改变设置，更改 Repeat 会清空完成历史。涉及重复任务或单次发生改期时，先核对模型能否表达，不直接改整个系列。
4. 通过已有逻辑维护重点等引用，不留下旧日期的无效重点。禁止删除重建、换包 Id、清除导入标记或修改模板来模拟更新。若获准改文字，标题最多 120 字符、说明 4000、下一步 500；分钟有效值为 1–480，既有空值未获准则保留。

【应用、验证与交付】
“预览差异”只交付方案；“执行”对确认无歧义的对象继续完成。写入前确认组件已退出且保存，核对路径并备份相关状态文件；运行时不可覆盖 state.json。
先用独立临时副本验证方案、保存、历史与非目标条目；应用前确认真实源数据没有发生新变化，再用受控读改写及既有保存机制应用。检查 LastSaveError 并重新读取目标状态验证，不能仅凭调用返回值声称成功。
交付最终差异、日期与每日预算、实际修改数量、未改条目、备份位置、验证结果和查看步骤。区分“预览已生成”与“已调整并验证”；访问受限、无法退出或保存失败时说明未完成动作。若需改代码，保持轻量离线和旧数据兼容并完成适用检查，不顺带重构导入系统。
```

## 填写示例

以下只是填写示例；实际使用必须提供真实任务列表，并与上方完整 Prompt 一起执行，不表示任务已改期。

```text
课程或计划：已导入的操作系统原理
目标任务：使用我附表中的真实 Id，逐项核对原标题和原日期
目标日期范围：2026-10-12 至 2026-10-23
调整方式与允许修改字段：保持原顺序重新排期，仅修改 Date
暂停日期、可学习日期与每日预算：2026-10-14 至 2026-10-16 暂停；只排周一至周五；每天共 30 分钟
必须保留的内容：完成记录、正文、下一步、时长、提醒及章节顺序
目标数据：按当前实例查找并核对
应用方式：预览差异
```
