# 08 · 修改计划相关功能

适用于能访问仓库的 AI 编程助手，按明确需求扩展排课、时刻、提醒或更新能力。用此模板控制修改范围，并保护既有计划与完成记录。

## 可复制 Prompt

```text
你是时屿的开发助手。请实现下面指定的计划功能，保持现有原生 C# / WinForms 架构，交付可使用的新构建及操作步骤。

【参数】
具体功能：[例如按星期排课、固定开始时刻、提醒开关]
用户操作与预期结果：[用输入和结果举例]
生效范围：[新导入学习包 / 指定已有任务 / 两者；明确对象]
日期、星期与暂停日规则：[填写；未涉及写“不改变”]
时刻、预计时长与提醒规则：[填写；未涉及写“不改变”]
重复任务规则：[填写；未涉及写“不改变”]
数据兼容和更新要求：[默认旧数据正常加载，保护完成记录和手动修改]
验收标准：[列出可以验证的行为]
实际数据操作：[默认不修改实际计划，使用临时数据验证]

【先确认实现】
读取项目指令、README.md、每日任务实现说明.txt、相关 src/Core.cs、src/LearningPack.cs、src/UniversityPacks.cs、src/ExtrasCore.cs、src/ExtrasView.cs、src/ExtrasDialogs.cs、src/Dialogs.cs、build.ps1 及 tests。
当前内置包按开始日期与 Day 日历偏移导入，默认无时刻、无重复、提醒关闭；旧任务没有可靠来源包与任务标识，不假定有批量更新接口。以源码为准，说明差距后实施。

【实施规则】
1. 只实现指定功能和必要联动，不顺带重写系统或迁移全部历史。目标或对象不明确时集中询问，其余常规选择自主完成并说明。
2. 排课区分学习日与日历跨度，按实际开始日期跳过休息日、暂停日并保持顺序；预览显示 YYYY-MM-DD 日期，换开始日期后重算。无可学习日、日期溢出须报错。
3. 固定时刻正确映射任务种类、MinuteOfDay、重复和提醒，按用户当地时间规则执行，不只写入标题。预计分钟是用时预算；核对 UI、核心校验及冲突规则。
4. 新增导入/批量更新契约时定义格式版本、稳定包和来源任务标识，与运行时 Id 区分；完整校验和预览后提交，明确新增、更新、跳过、冲突及重复规则。失败无部分写入。仅改文案不强加外部格式。
5. 已有任务须可靠定位，默认只改范围内未完成项；保留 Id、完成状态/日期、重复完成记录、专注统计、用户编辑及重点引用。不按相似标题覆盖、不删除重建、不改包 Id 或清标记强迫导入。
6. UpdateItem 显式保留原 Repeat、ReminderEnabled。当前改变重复规则可能清空完成记录；需求明确改变时实现并验证历史保护。来源不明的旧实例不自动推断映射。
7. 新字段设旧数据缺省值，内置包、手动计划和历史兼容。按实际校验，标题不超过界面 120 字符、说明 4000、下一步 500、预计分钟 1–480，避免重启截断。
8. 默认不调整实际数据。参数明确要求时先核对范围并备份，用受控保存机制操作，不覆盖运行中的 state.json；保存失败恢复一致状态并报告失败。

【验证与交付】
在独立临时数据中验证验收标准和相关边界。涉及排课时检查不同起始星期、周末、暂停日、日预算和日期溢出；涉及更新时检查重复操作、用户修改冲突、完成历史、重点引用、保存失败、重启及旧数据兼容。
在仓库根目录运行适用构建与测试；原程序运行时优先使用 ./build.ps1 -Test -OutputPath ./artifacts/时屿-待替换.exe 并保留 .config。涉及界面时检查实际入口、预览与结果提示。
数据提交成功须检查 LastSaveError 并重新读取验证；不能仅凭内存变化或返回数量认定保存成功。
交付功能前后行为、改动文件、实际测试结果、使用的新程序和具体操作步骤。清楚说明是否修改了实际计划及仍未验证的限制。
```

## 填写示例

把下面内容填入上面的完整 Prompt；示例用于填写需求，不能单独执行。

```text
具体功能：学习包导入支持选择可学习星期和每天固定开始时刻
用户操作与预期结果：选择周一至周五、19:30，10 个学习日从 2026-10-05 开始，结束于 2026-10-16
生效范围：只影响新导入学习包，现有任务不调整
日期、星期与暂停日规则：跳过周末，允许额外暂停日期，更换开始日期后重新计算
时刻、预计时长与提醒规则：每日第一项 19:30，后续按预计分钟顺排；默认提醒关闭，可由用户开启
重复任务规则：导入的每项仍为一次性任务
数据兼容和更新要求：旧数据、已完成记录及现有每日重点保持可用
验收标准：预览显示真实日期与时刻；重复导入不新增；保存后重启结果一致
实际数据操作：不修改实际计划，使用临时数据测试
```
