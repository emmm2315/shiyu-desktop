# 学习计划 Prompt 合集

这里提供 8 个场景模板和 1 个通用模板，帮助你设计学习计划、把计划接入时屿、调整已有安排，或让 AI 编程助手修改相关功能。

普通聊天 AI 可以使用“设计计划”和“审查计划”模板。需要接入学习包、修改程序或更新本机任务时，请在能访问本仓库及相关数据的 AI 编程助手中使用对应模板。

## 如何使用

1. 打开需要的模板，复制“可复制 Prompt”中的整个代码块。
2. 把方括号中的占位内容替换成自己的课程、资料、日期和要求。示例用于帮助填写，不能替代完整 Prompt。
3. 提供教材、课件、已有计划或目标任务列表。普通聊天 AI 无法读取的本机资料，需要通过该工具支持的方式提供。
4. 在对应能力的 AI 工具中执行。接入学习包后，按交付说明使用新构建，再在组件中选择开始日期加入。
5. 调整已导入任务时，明确目标课程、条目及日期范围。不要把“修改模板”和“更新已有任务”混为同一操作。

每份场景模板的主代码块都可以独立使用。能访问仓库的助手也可以先读取对应 Markdown 文件，再按你的填写内容执行。

## 当前实现与模板的关系

以下说明对应本仓库 v1.2.1；如果后续代码发生变化，以实际实现为准。

- 学习包目前定义在源码中，通过组件的学习任务包菜单按开始日期导入。当前内置 8086 寄存器、操作系统原理、算法分析与设计三门课程。
- 同一个包 Id 只导入一次；换一个开始日期也不会自动创建第二批。修改模板不会更新已经导入的任务。
- 学习包用 `Day` 表示从开始日期起的日历天偏移。限制星期或跳过周末时，需要结合实际导入日期计算，不能仅修改说明文字。
- 已导入任务目前没有可靠的课程包和来源任务标识，批量修改前需要确认目标条目。
- JSON 文件导入、基于稳定来源标识的批量更新等能力，是模板 07 要求开发的功能。这里提供的 Prompt 不代表这些功能已在程序中实现。
- 计划详情、下一步和预计用时已具备本机保存能力；导入结果仍应通过实际保存与重新读取核验。

## 常用填写例子

新建课程可以填写“14 个学习日、每天 30 分钟、周一至周五、概念 10 分钟加练习 20 分钟”。学习日数量和日历跨度不同，请给出开始日期，或要求导入时按所选日期计算。

调整已有计划可以填写“只修改这些未完成任务，下周三至周五暂停，后续任务顺延到可学习日，每天不超过 30 分钟；已完成任务保持原样”。同时提供足以核对目标条目的信息。

如果希望普通聊天 AI 将来生成文件后直接导入，先用模板 07 实现并验证文件导入功能，再使用实际交付的格式规范生成文件。
