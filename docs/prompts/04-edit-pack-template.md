# 04 · 修改学习包模板

适用于修改课程内容，供以后首次导入使用。模板改动不会更新已导入任务；调整既有任务请使用 [05 · 调整已导入计划](05-reschedule-imported-plan.md)。

## 可复制 Prompt

```text
你是时屿的学习包维护助手。只修改指定内置模板及相关练习说明，生成构建供以后首次导入使用，本次不修改已导入任务和真实数据。

【填写参数】
目标包 Id 或准确名称：[填写]
目标学习日、任务或主题：[明确范围]
修改要求：[填写]
必须保留的内容：[填写]
教材或依据：[仓库相对路径、章节或粘贴资料]
周期、预算与日期规则：[保持原样，或填写新要求]

【执行规则】
1. 所有路径与命令相对于仓库根。先读项目指令、README.md、src/LearningPack.cs、src/UniversityPacks.cs、src/ExtrasView.cs、src/ExtrasDialogs.cs、build.ps1、对应“课程练习”文件及测试。核对包 Id、任务数组、预览与导出；对象有歧义时集中询问。
2. 保留稳定包 Id，只改指定范围及直接相关文档。当前按包 Id 只导入一次，模板不会同步到 PlanItem；不得换 Id、清除 ImportedLearningPacks 标记或删除旧任务来模拟更新。
3. 修改练习、提示、完成标准和下一步，保留获准范围以外的内容，不编造页码或题号。同步练习文件、预览、导出和适用来源，防止不同版本并存。
4. 标题最多 120 字符、Detail 最多 4000、NextStep 最多 500，Minutes 为整数 1–480；每日合计符合预算，超长正文放练习文件。导入直接构造任务，模板须完整校验。
5. Day 从 0 开始表示日历偏移，包 Days 为最大偏移 + 1；区分学习日数和含休息日的日历跨度。按星期排课须依最终开始日期计算，或限制到核定日期。任务数变化时同步摘要、提示及“每天两项”等固定文案。
6. 保持原生轻量离线、默认一次性任务及既有重点规则。修改只影响尚未导入该包的用户；已导入用户需另行核对具体任务，不能绕过去重。

【验证与交付】
仅改文档时检查文本与字段限制；只要改源码就构建，按行为变化选择适用测试，不为文字修改新增镜像测试。可用 .\build.ps1 -Test -OutputPath .\artifacts\时屿-待替换.exe，保留 .config，不覆盖运行中的程序。
用独立临时数据验证首次导入、数量、日期、预算和同包再次导入被阻止；检查 LastSaveError，再重新读取确认保存及旧任务保留。
交付包 Id、前后对照、改动文件、构建路径、实际验证结果及首次导入步骤。明确模板已更新、已导入实例不会自动更新、同包仍只导入一次；未完成检查如实说明。
```

## 填写示例

以下是参数填写示例，请替换上方完整 Prompt 的参数后执行，不表示模板已经修改。

```text
目标包 Id 或准确名称：algorithm-design-v1
目标学习日、任务或主题：Day=6 与 Day=7 的动态规划和 0/1 背包任务
修改要求：增加逐步填写状态表的引导，把答案提示放在说明末尾
必须保留的内容：14 天 28 项、总顺序与其他学习日的题目
教材或依据：使用包内原有例子，不新增教材题号
周期、预算与日期规则：连续 14 日，每天 30 分钟，保持原样
```
